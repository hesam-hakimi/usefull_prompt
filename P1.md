# Prompt 1 — Verified Current Architecture

You are a Principal Enterprise Cloud Architect.

Generate or update the **CURRENT** askAlpha architecture only from private-repository code, configuration, packaging, deployment, and wired runtime evidence.

Do not infer current components from roadmap documents, meetings, target diagrams, or unused configuration.

## Verified baseline to preserve unless newer private evidence contradicts it

- Vite builds React static assets under `src/frontend/build`.
- React static assets and FastAPI are packaged together in one Azure App Service artifact.
- FastAPI/Uvicorn serves both the SPA and API.
- Browser/API traffic is same-origin HTTPS using JSON REST and SSE (`POST /api/chat/stream` with JSON fallback).
- MSAL obtains the Entra token in the browser.
- The browser sends `Authorization: Bearer` to FastAPI.
- FastAPI validates JWTs using Entra JWKS, issuer, audience, scope, group-overage, and stable-user checks.
- Primary and fallback orchestrators are current; agents are route-dependent.
- Azure OpenAI is called directly through the SDK/AutoGen configuration; no live enterprise LLM Gateway exists.
- Azure SQL handles analytics plus authorization/control/diagnostic responsibilities.
- Azure AI Search is conditional fallback metadata text search; it is not the primary analytical engine and is not vector/hybrid retrieval.
- User-assigned Managed Identity is current.
- Validation is in-process application logic; no standalone validation service exists.
- Redis is configured but unused.
- User-query/export audit is absent; data-access audit is partial.

## Do not show as current

- separate React hosting, CDN, Static Web App, or second App Service;
- enterprise LLM Gateway;
- Redis runtime cache;
- Databricks, ADLS, Event Hubs, usage collector, durable outbox;
- LangSmith, Azure Sentinel, Dynatrace, or Datadog runtime monitoring;
- full user/data/export audit;
- vector/hybrid Azure AI Search;
- standalone validation service.
