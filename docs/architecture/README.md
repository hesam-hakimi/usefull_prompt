# askAlpha Architecture Pack

This package contains three versioned Mermaid architecture diagrams:

1. **Current Deployment Architecture** — current implementation evidence.
2. **MVP1 SpruceX Architecture** — planned state after access and data-product onboarding.
3. **Target Enterprise Production Architecture** — future enterprise target.

## Important status rule

Do not present MVP1 or Production components as implemented unless the private repository, deployment configuration, and platform evidence confirm them.
